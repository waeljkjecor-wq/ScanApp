# تطبيق سكنر + باركود (أندرويد)

تطبيق تعليمي بلغة Kotlin وواجهة Jetpack Compose، بيه تبويبين:

- **باركود:** يقرأ QR والباركود، يحفظ سجل، ومنه تقدر تنسخ أو تفتح الرابط أو تشاركه.
- **سكنر:** تصوّر صفحة ورا صفحة (لحد 30) أو تختار صور من المعرض، وبالأخير تطلع كلهن بملف PDF واحد. السكنر يقص الورقة ويعدل زاويتها تلقائياً، وبيه فلاتر وتدوير.

## شلون تشغّله

1. نصّب **Android Studio** (آخر إصدار).
2. فك الضغط عن الملف، وافتح مجلد `ScanApp` من: File → Open.
3. انطر Android Studio لحد ما يخلص الـ Gradle Sync (أول مرة ياخذ كم دقيقة لأنه ينزل المكتبات).
4. وصّل موبايلك بالكيبل وفعّل **USB debugging** من خيارات المطور.
5. اضغط زر ▶ Run.

> **مهم:** المكتبات تحتاج **Google Play Services**، فجرّبه على موبايل حقيقي، أو على محاكي صورته مكتوب عليها "Google Play".

## الملفات

| الملف | شنو بيه |
|---|---|
| `app/build.gradle.kts` | المكتبات المستخدمة وإصدار أندرويد |
| `AndroidManifest.xml` | اسم التطبيق والإعدادات |
| `MainActivity.kt` | الشاشة الرئيسية والشريط السفلي |
| `BarcodeScreen.kt` | قارئ الباركود والسجل |
| `ScannerScreen.kt` | السكنر، الـ PDF، المشاركة والحفظ |

## المكتبات الأساسية

- `play-services-code-scanner`: قارئ باركود جاهز من Google، وما يحتاج صلاحية كاميرا.
- `play-services-mlkit-document-scanner`: سكنر مستندات جاهز من Google، بيه عدة صفحات وتصدير PDF.

## أفكار تطورها بعدين (تمارين)

1. تسمية الملف قبل الحفظ بدل `scan_تاريخ.pdf`.
2. توليد QR من نص أو رابط.
3. البحث داخل سجل الباركود.
4. كتابة كاميرا خاصة بيك باستعمال CameraX بدل الشاشة الجاهزة، وهذا تمرين متقدم.
